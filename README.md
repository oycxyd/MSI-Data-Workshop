# MSI-Data-Workshop
worked notebooks and data for the practical part of MSI Data Analysis

## *Before you start, please install the latest Anaconda (Sep. 2026) and have pulled this repository locally

# Setup
- Open Anaconda Prompt by the search bar or otherwise:
<img width="896" height="956" alt="image" src="https://github.com/user-attachments/assets/e8209380-9e81-44f8-8ef7-11160741e443" />

- type:
  
  `conda env create -f TUMD4.yml`

  this should create an environment with the correct dependencies called TUMD4.

- Activate the environment and start Jupyter Lab by:

`conda activate TUMD4`

`jupyter lab`

- there are 2 notebooks to work through, you can find them under the root directory of your local repository, e.g.,:
